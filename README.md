# Desafio Harpia
**Autor**: Kayky Gabriel

**Objetivo do programa:**
Este programa foi criado para calcular se um robô teria bateria suficiente para realizar uma missão completa.

**O que é necessário para executá-lo:**
- Linguagem Python instalada
- Um Terminal Linux (ou WSL)

**Comando de execução (a partir da pasta principal):**
`python3 src/missao.py`

**Exemplo de entrada e saída:**
- **Entrada:** Bateria 78%, Duração 25 min e Consumo 4% por min
- **Saída:** A missão não pode ser concluída. Faltam: 22.0%.
